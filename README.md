## 📖 Descripción General

Este repositorio contiene el portafolio integral de evidencias correspondientes a los proyectos desarrollados durante el semestre en la asignatura de Desarrollo de Aplicaciones para Dispositivos Móviles.

El propósito principal es documentar la evolución técnica obtenida durante el curso, abarcando desde aplicaciones de consola desarrolladas en Dart hasta aplicaciones móviles construidas con Flutter utilizando programación reactiva, gestión de estado y componentes multimedia.

---

## 🎯 Competencias Desarrolladas

Durante la elaboración de los proyectos se fortalecieron las siguientes competencias:

* 🎨 **Diseño de Interfaces (UI/UX):** Construcción de interfaces modernas mediante el sistema de widgets de Flutter.
* 🧠 **Gestión del Estado:** Implementación de estado global y local utilizando Provider.
* 💻 **Programación Orientada a Objetos:** Uso de clases, constructores, encapsulamiento y manipulación de colecciones.
* ⚡ **Programación Asíncrona y Reactiva:** Manejo de Streams, Future y procesamiento de eventos en tiempo real.
* 🔧 **Control de Versiones:** Administración profesional del código mediante Git y GitHub.
* 📂 **Persistencia y Manejo de Datos:** Lectura, escritura y procesamiento de archivos JSON.

## 🚀 Proyectos Incluidos

### 📊 Proyecto 1 — Análisis de Datos con Dart

Aplicación CLI desarrollada en Dart puro para la lectura y procesamiento de archivos JSON. Permite realizar búsquedas, filtros dinámicos, generación de estadísticas y exportación de reportes.

**Temas aplicados:**

* Programación Orientada a Objetos
* Null Safety
* Manejo de archivos
* Procesamiento de datos JSON

---

### 🎲 Proyecto 2 — Generador de Nombres Aleatorios

Aplicación Flutter enfocada en la construcción de interfaces reactivas utilizando Provider para la administración de estado global y almacenamiento de favoritos.

**Temas aplicados:**

* Flutter Widgets
* Provider
* Navegación
* Diseño responsivo

---

### 🎵 Proyecto 3 — Mini Reproductor de Música

Aplicación móvil que integra reproducción de audio y sincronización en tiempo real mediante programación reactiva.

**Temas aplicados:**

* just_audio
* RxDart
* Streams
* Gestión multimedia
